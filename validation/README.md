# 合成固定窗口校验器

在本目录用 Python 3 运行，依赖仅为标准库。

```text
python verify_window.py fixed_window.json
```

这是 用于验证源时钟和窗口边界的离线合成验证样例。JSON 中的预期标签可独立人工核对，命令逐条计算实际标签并报告差异。退出码为 0 表示全部匹配，1 表示标签有差异，2 表示输入或用法无效。

源窗口在声明时钟域内采用 `[start, deadline)`。同域事件归为 `in_window` 或 `outside_window`，空域或其他时钟域归为 `unknown_clock`。源 tick 与接收 tick 使用无符号十进制字符串，保留超过 2^53 的整数精度。接收侧单独记录时钟、tick 和顺序。结束标记 `observed_end` 用于描述接收顺序，窗口成员资格仅由源时钟和截止 tick 判定。样例覆盖结束标记之后才收到的窗内事件，以及源时间在截止之后、却在延迟结束标记之前收到的窗外事件。

校验器拒绝重复 JSON 键、事件标识和接收序号，也拒绝缺失或多余字段，以及无效标签、tick 或区间。结果只适用于本合成输入的窗口判定。时钟同步、现场采集覆盖和丢失率由后续验证给出。
